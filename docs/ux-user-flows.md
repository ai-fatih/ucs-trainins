# User Flows — UCS Service Portal

## Роли пользователей

| Роль | Описание | Auth-состояние |
|------|----------|----------------|
| **Гость** | Неавторизованный посетитель лендинга | Не авторизован |
| **Сотрудник ресторана** | Пользователь, который хочет обучиться/получить консультацию | Авторизован (individual/company) |
| **Руководитель** | Руководитель ресторана, обучает команду | Авторизован (company_admin) |
| **Менеджер отдела** | Сот UCS service, проводит консультации | Авторизован (staff/admin) |

---

## Flow 1: Гость → Регистрация → Первые шаги

**Цель:** познакомиться с порталом и зарегистрироваться.

```
/ (лендинг)
  │
  ├─ Читает Hero, About → понимает, чем помогает отдел
  │
  ├─ Смотрит Документацию (#docs) → /docs → /docs/rkeeper/* → изучает инструкции
  │   └─ (не нужна авторизация)
  │
  ├─ Смотрит Услуги (#services) → /services → выбирает категорию
  │   └─ Нажимает "Записаться" → AuthModal → /auth/login
  │
  ├─ Смотрит Школу (#school) → /school → AuthModal (требуется авторизация)
  │
  └─ Нажимает "Личный кабинет" (хедер) → AuthModal → /auth/register
      │
      ├─ Заполняет форму → подтверждает
      └─ → / (авторедирект) → хедер показывает аватар + уведомления
```

**Проблема:** после регистрации пользователь попадает на `/` — не清楚, куда идти дальше.

**Решение (Фаза 2):** после регистрации → `/dashboard` (персональный дашборд).

---

## Flow 2: Сотрудник — Запись на консультацию

**Цель:** записаться на консультацию/обучение по rkeeper.

```
/auth/login
  │
  ├─ → /dashboard (видит: нет записей, "Новая запись")
  │
  └─ /dashboard → "Новая запись" → /booking
      │
      ├─ Шаг 1: Выбор услуги → /services (контекст) → /booking?serviceId=X
      ├─ Шаг 2: Выбор даты/времени → календарь + слоты
      └─ Шаг 3: Подтверждение → ввод темы → "Подтвердить"
          │
          └─ → /bookings (запись создана, toast)
              │
              ├─ Видит upcoming запись → "Открыть чат" → /chat/[id]
              ├─ После консультации → "Оставить отзыв" → /review
              └─ После консультации → "Оценить" (оплата/чаевые — заглушка)
```

**Проблемы:**
- Нет выбора специалиста в визарде (только через query-параметр)
- Календарь — заглушка (июль 2026)
- Нет связи "записался на консультацию" → "прошёл урок в школе"

**Решение (Фаза 2-3):**
- Добавить шаг выбора специалиста в booking
- Связать бронирование с прогрессом школы

## Flow 3: Сотрудник — Обучение в школе

**Цель:** изучить материал по rkeeper в удобном темпе.

```
/auth/login
  │
  └─ → /school (dashboard школы)
      │
      ├─ Смотрит XP, streak, уровень → мотивация
      │
      ├─ /school/courses → выбирает курс
      │   └─ /school/courses/[id] → модули → уроки
      │       └─ /school/courses/[id]/lessons/[lid] → проходит урок
      │           ├─ Читает материал → завершает → +XP
      │           └─ → следующий урок → возврат к курсу
      │
      ├─ /school/leaderboard → сравнивает с другими
      ├─ /school/badges → смотрит награды
      └─ /school/certificates → смотрит сертификаты
```

**Проблема:** нет связи школы с консультациями. Пройдя урок по StoreHouse, сотрудник не может записаться на консультацию по StoreHouse.

**Решение (Фаза 2):** на странице курса добавить CTA "Записаться на консультацию по теме".

---

## Flow 4: Сотрудник — Управление записями

**Цель:** отследить, отменить или оценить запись.

```
/dashboard
  │
  ├─ Видит "Мои записи" → /bookings
  │   │
  │   ├─ Предстоящие:
  │   │   ├─ "Открыть чат" → /chat/[id] → общается с менеджером
  │   │   └─ "Отменить" → подтверждение → запись отменена
  │   │
  │   ├─ Проведённые:
  │   │   ├─ "Оставить отзыв" → /review → оценка + комментарий
  │   │   ├─ "Оценить качество" → модальное окно опроса
  │   │   └─ "Отблагодарить" → TipModal → заглушка "скоро"
  │   │
  │   └─ Все:
  │       └─ полная история записей
  │
  └─ /profile → настройки аккаунта → /notifications → настройки уведомлений
```

## Flow 5: Руководитель — Обучение команды

**Цель:** обучить сотрудников, отследить прогресс.

```
/auth/login (company_admin)
  │
  └─ → /school (dashboard)
      │
      ├─ Смотрит общий рейтинг → /school/leaderboard
      │   └─ Видит топ сотрудников, их XP
      │
      ├─ Записывает сотрудников на курсы
      │   └─ /school/courses → назначает курсы
      │
      ├─ Смотрит сертификаты команды → /school/certificates
      │
      └─ Записывает на консультацию → /booking
          └─ (для конкретного сотрудника)
```

**Проблема:** нет вью прогресса команды на одной странице.

**Решение (Фаза 2):** добавить на дашборд школы виджет "Прогресс команды" для company_admin.

---

## Flow 6: Менеджер — Обработка заявок

**Цель:** обработать входящие заявки, провести консультацию.

```
/admin/login
  │
  └─ → /admin/requests (список заявок)
      │
      ├─ Смотрит дашборд KPI → /admin/dashboard
      │   ├─ Сегодняшние консультации
      │   ├─ Загрузка специалистов
      │   └─ Последние заявки
      │
      ├─ /admin/requests → выбирает заявку
      │   └─ /admin/requests/[id]
      │       ├─ Меняет статус (new → in_progress → done)
      │       ├─ Оставляет комментарий
      │       ├─ Генерирует feedback-ссылку → /feedback/[token]
      │       └─ Клиент получает ссылку → оценивает
      │
      └─ Общается с клиентом через чат → /chat/[id]
```

## Ключевые insights для Фазы 2-3

### Сквозные связи (нужно реализовать)

| Откуда | Куда | Почему |
|--------|------|--------|
| `/school/courses/[id]` | `/booking` | "Записаться на консультацию по теме курса" |
| `/dashboard` | `/school` | "Продолжить обучение" виджет |
| `/booking` (шаг 3) | `/specialists` | Выбор специалиста в визарде |
| `/auth/register` → success | `/dashboard` | Не на `/`, а на дашборд |
| `/bookings` (completed) | `/review` | Прямая ссылка, а не через actions |
| `/school` (admin view) | `/booking` | "Записать сотрудника на консультацию" |
| Юридические страницы | Назад | "← Вернуться на сайт" |
| `/specialists` | Хедер/навигация | Нет ссылки на эту страницу |
| `/request` | Лендинг/навигация | Нет ссылки на эту страницу |

### Мёртвые зоны (нужно убрать/переделать)

| Проблема | Решение |
|----------|---------|
| `admin/schedule` — редирект | Удалить route или реализовать |
| `/school/certificates` — нет действий | Добавить скачивание/шаринг |
| `/school/profile` — read-only | Добавить редактирование или убрать |
| `/school/notifications` — mock | Объединить с `/notifications` или убрать |
| `/notifications` — нет "Назад" | Добавить ссылку на `/profile` |
| Юридические страницы — нет "Назад" | Добавить "← Вернуться на сайт" |
