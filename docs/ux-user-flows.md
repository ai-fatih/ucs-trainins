# User Flows — UCS Service Portal

> **Актуализация 03.08.2026:** текущий контур — публичный информационно-обучающий портал без ЛК. Авторизация и роли (гость/сотрудник/руководитель/менеджер) удалены; все сценарии — анонимные гостевые.

---

## Flow 1: Гость — знакомство с порталом

**Цель:** понять, чем помогает отдел, и найти нужный контент.

```
/ (лендинг — Hero-хаб без скролла)
  │
  ├─ Выбирает CTA → /docs → список инструкций → /docs/[id] → изучает процесс
  ├─ Выбирает CTA → /school → каталог курсов
  ├─ Наводит на панель «Популярное · месяц» → /faq (годовой срез обращений)
  ├─ Наводит на «?»/элементы → подсказки («Что здесь», «Что сделано»)
  ├─ Нажимает `2` → /school или `3` → /faq (шорткаты работают только на лендинге)
  ├─ Нажимает Ctrl + 5 → SearchDialog → переходит на страницу/курс
  └─ Выбирает CTA → соответствующий раздел
```

Авторизация не требуется ни на одном шаге. Секции О нас/Документация/Школа, Услуги/Новости/Отзывы/FAQ и CTA-заявка на лендинге убраны.

## Flow 2: Гость — обучение в школе

**Цель:** изучить материал по r_keeper в свободном темпе.

```
/ → /school → каталог курсов
  │
  ├─ /school/courses → выбирает курс
  │   └─ /school/courses/[id] → модули → все уроки открыты
  │       └─ /school/courses/[id]/lessons/[lid] → проходит урок
  │           ├─ Читает материал → отвечает на задания (квиз/спринт/сопоставление/цепочка/кейс)
  │           └─ Финальный экран «Урок завершён!» → следующий урок / к курсу / на главную
  │
  └─ Из обращения /faq/[month]/[caseId] → «Потренироваться в школе»
      └─ /school/courses/{courseId}/lessons/{lessonId} → дерево решений по кейсу
```

Прогресс сохраняется локально (localStorage `ucs_school_progress`): пройденный урок отмечается в модулях курса, панель прогресса показывает долю и предлагает «Продолжить урок».

---

## Flow 3: Гость — от обращения к решению (ядро «Обращение → Инструкция → Школа»)

**Цель:** от типового вопроса пользователя дойти до готового решения и закрепить практикой.

```
/ (лендинг — панель «Популярное · месяц») → /faq — годовой срез
  │
  ├─ /faq → выбирает месяц → /faq/[month] (итоги + список обращений)
  │   └─ /faq/[month]/[caseId] — краткая карточка обращения
  │       ├─ «Читать инструкцию» → /docs/[instructionId] → шаги + типовые ошибки
  │       │     └─ «из каких обращений» → /faq/2026-07/[caseId]
  │       └─ «Потренироваться в школе» → /school/courses/{courseId}/lessons/{lessonId}
  │             └─ дерево решений → закрепляет навык
  └─ /docs (список инструкций) → /docs/[id] → CTA «Потренироваться в школе»
```

## Сквозные связи (текущий контур)

| Откуда | Куда | Статус |
|--------|------|--------|
| `/docs` (блок «Популярные обращения») | `/faq` | ✅ |
| `/faq` (год) | `/faq/[month]` | ✅ |
| `/faq/[month]/[caseId]` | `/docs/[instructionId]` (инструкция) + `/school/courses/{courseId}/lessons/{lessonId}` (тренажёр) | ✅ |
| `/docs/[id]` | «из каких обращений» `/faq/2026-07/[caseId]` + тренажёр | ✅ |
| завершённый урок | следующий урок / к курсу / на главную | ✅ |
| `/` (панель «Популярное»), footer | `/school`, `/docs`, `/faq` | ✅ |
| Горячие клавиши `1/2/3` (только лендинг) | `/docs`, `/school`, `/faq` | ✅ |
| Поиск (Ctrl + 5) | страницы, инструкции, `/faq/[month]`, курсы | ✅ |
| Подсказки («?» / hover-тултипы) | карточка «Что здесь / что сделано» | ✅ |
| Несуществующий URL | 404 → поиск / разделы | ✅ |
| Юридические страницы | «← На главную» | ✅ |
