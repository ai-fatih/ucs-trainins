# Информационно-обучающий портал UCS Trainings (без личного кабинета)

**Дата:** 03.08.2026
**Статус:** справка на согласование
**Ветка-архив текущей реализации:** `main-arhive`

---

## Ситуация

Отдел консультации и обучения — часть компании. Для полноценного продукта (личный кабинет, запись, чат) нужны API и разрешения от компании — пока их нет. Данных пользователей и внешних систем нет.

Но у отдела есть главный актив — **база знаний**: кейсы обращений, которые операторы обрабатывают каждый день. Именно на нём строится новый вариант.

## Решение

Открытый без авторизации информационно-обучающий портал:

1. **Документация** — пошаговые инструкции по продуктам r_keeper (уже есть).
2. **«Разбор кейсов месяца»** — реальные обращения за прошлый месяц, оформленные по единому шаблону:
   *ситуация → симптомы → диагностика → причина → решение → профилактика*, с сегментацией по продукту/теме.
3. **Школа-тренажёр** — интерактивные тренажёры на этих же кейсах (деревья решений, викторины, сопоставления, процедуры). Без авторизации, прогресс хранится локально на устройстве.
4. **Публичная заявка без входа** — форма запроса консультации (уже работает) для сбора обращений.

Текущая полная реализация (ЛК, запись, чат, админка) сохранена в ветке `main-arhive` и вернётся на шаге после получения одобрения/API.

## Как это работает

- Ежемесячно отдел оформляет топ-кейсы месяца в едином шаблоне → они автоматически появляются в разделе «Кейсы месяца» и в тренажёре школы.
- Портал открыт без логина; тренажёр запоминает прогресс пользователя локально.
- Раздел «Кейсы месяца» связан с тренажёром: из разбора можно сразу перейти к тренировке на этом кейсе.

## Преимущества для кого

| Кто | Выгода |
|-----|--------|
| **Операторы 1-й линии** | Готовые разборы типовых ситуаций, единый стиль ответов, меньше эскалаций |
| **Маркетинг** | Готовый контент по популярным вопросам месяца, SEO, понимание спроса клиентов |
| **Стажёры отдела** | Тренажёр на реальных кейсах — быстрый онбординг без нагрузки на старших |
| **Отдел продаж** | Знание частых болей клиентов, аргументы для переговоров |
| **Клиенты** | Самообслуживание и обучение — соответствует миссии «пользователь, который умеет работать» |
| **Нам (отдел)** | Системная привычка описывать и сегментировать кейсы → база знаний и аналитика |

## Что дальше

После одобрения и получения API подключаем личный кабинет, запись, чат. Полная текущая реализация не теряется — она в ветке `main-arhive`.
