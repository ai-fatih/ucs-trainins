## Проблемы, выявленные инвентаризацией

### Дубли
1. **`/notifications` (глобальные) vs `/school/notifications`** — разные страницы с похожей целью. Первая — настройки каналов, вторая — список уведомлений школы. Разные назначения — ок, но нет cross-link между ними.

### Разрывы (нет связи)
2. **School → Booking**: из школы нельзя записаться на консультацию по пройденной теме
3. **Dashboard → School**: на дашборде нет прогресса школы
4. **Booking → Specialists**: в визарде бронирования нет выбора специалиста
5. **`/notifications` → `/profile`**: нет обратной ссылки
6. **`/specialists`**: ниоткуда нет ссылки на эту страницу
7. **`/request`**: ниоткуда нет ссылки на эту страницу

### Мёртвые страницы (нет навигации назад)
8. `terms`, `privacy`, `offer`, `consent` — только футер, нет выхода
9. `school/certificates`, `school/notifications`, `school/profile` — только "На главную"
10. `admin/schedule` — редиректит на requests (можно удалить)

### Заглушки
11. `/booking` — календарь только июль 2026
12. `/review` — жёстко зашит специалист
13. `/docs/rkeeper/event` — "Раздел готовится"
14. TipModal — "скоро появится"
15. Оплата — только текст в оферте, нет реализации
