# Точки касания — вход и выход

Правила для экранов: где пользователь входит, куда выходит, какие действия доступны.

Статусы: ✅ реализовано · ⚠️ частично/заглушка · 🔧 в разработке

---

## Правила

1. **Каждый экран отвечает на 4 вопроса:** «Где я?» (breadcrumbs), «Откуда пришёл?» (назад), «Куда дальше?» (CTA), «Что ещё доступно?» (контекстная навигация).
2. **Выход на мёртвую страницу запрещён** — у каждого экрана есть хотя бы один выход (назад или на главную). См. `ux-navigation-architecture.md` §5.
3. **Авторизация отсутствует** — все маршруты публичные, редиректов и гостевых гейтов нет (информационно-обучающий контур, см. `brief-public-phase.md`).
4. **Изменение навигации/точек входа** — согласуется с этой схемой и `ux-navigation-architecture.md`, иначе появляются «разрывы» (страницы, на которые нет ссылок).

## Сквозные элементы (на всех страницах)

| Элемент | Компонент | Вход/действие | Выход |
|---------|-----------|---------------|-------|
| **Header** | `components/layout/Header.tsx` | Лого → `/`; табы секции (зависят от маршрута, из `navigation.json`); поиск (`SidebarSearch`); PWA-установка | Внутри страниц |
| **Footer** | `components/layout/Footer.tsx` | Ссылки на `/school`, `/school/courses`, `/docs`, `/docs/cases`, `/terms`, `/privacy`, `/offer`, `/consent` | — |
| **PhoneLink** | `components/PhoneLink.tsx` | Телефон отдела | Гидрация-безопасный tel-контакт |
| **CookieBanner** | `components/layout/CookieBanner.tsx` | Согласие на cookies | Кнопка «Принять» |

## Публичные страницы

| Точка | Вход | Выход | Статус |
|-------|------|-------|--------|
| **`/` Лендинг** | Прямой вход, поисковик, реклама | Hero → `/school`, `/docs`; блоки → `/docs`, `/school`, `/docs/cases`; контакты → mailto/tel | ✅ |
| **`/docs` Каталог** | Лендинг, header | → `/docs/rkeeper/{product}`, → `/docs/cases` | ✅ |

| **`/docs/cases/[id]`** | `/docs/cases` | → назад к кейсам, → тренажёр по кейсу (`/school/courses/cases-2026-07/lessons/…`) | ✅ |
| **`/terms`, `/privacy`, `/offer`, `/consent`** | Footer, формы | → «← Вернуться на сайт» | ✅ |
| **`/school` Школа** | Лендинг, header (таб Школа) | → `/school/courses` | ✅ |
| **`/school/courses`** | `/school` | → `/school/courses/[id]` | ✅ |
| **`/school/courses/[id]`** | `/school/courses` | → `/school/courses/[id]/lessons/[lid]` | ✅ |

## Проблемы (сводно)

1. **Удалено в этом контуре:** авторизация, ЛК, админка, услуги/специалисты/заявка, отзывы/новости/FAQ, голосовой ассистент и весь персонализированный слой школы (см. `feature-inventory.md`). Реализация сохранена в ветке `main-arhive` и в текущем контуре не возвращается.
2. **Лендинг** — только Hero + О нас + Документация + Школа. Секции услуг, новостей, отзывов и FAQ убраны. CTA Hero ведёт в `/school` и `/docs`.
3. **Мобильная навигация** — без сайдбара-шторки: табы header прокручиваются, поиск доступен с `md+`; навигация по разделам — через ссылки footer.

Подробная инвентаризация всех страниц — `docs/ux-page-inventory.md`.
