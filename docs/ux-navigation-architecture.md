# Navigation Architecture — UCS Service Portal

> **Текущая фаза — информационно-обучающий портал без ЛК** (см. `docs/brief-public-phase.md`). Авторизация, ЛК, админка, услуги/специалисты/заявка, отзывы/новости/FAQ и персонализация школы удалены; все маршруты публичные. Открыты `/`, `/docs`, `/docs/cases`, `/school/*` и правовые страницы. Удалённая реализация сохранена в ветке `main-arhive` и в текущем контуре не возвращается.

## Принцип навигации

Каждая страница должна отвечать на 4 вопроса:
1. **Где я?** — breadcrumbs + заголовок
2. **Откуда я пришёл?** — ссылка "назад"
3. **Куда идти дальше?** — CTA или links
4. **Что ещё доступно?** — контекстная навигация (хедер/сайдбар)

## 1. Header — контекстная навигация

### Лендинг (`/`)
```
UCS service | Документация | Школа | 🔍
```
> На лендинге табы ведут на страницы `/docs` и `/school`; якорных секций больше нет — лендинг это полноэкранный Hero-хаб без скролла.

### Документация (`/docs/*`)
```
UCS service | Документация | Школа | 🌙 🔍      ← Header единый, табы топ-уровня, тумблер темы
│  ┌───────────── sidebar (doc-центр) ─────────────┐
│  │ Все инструкции                                 │
│  │ Десктоп    ▸ r_keeper 7 ▸ StoreHouse Pro       │
│  │ Облачные   ▸ Delivery  ▸ Event                 │
│  │ Мобильные  ▸ Waiter & Cash Desk                │
│  │ Кейсы месяца ▸ Разбор обращений                 │
│  └────────────────────────────────────────────────┘   [контент страницы]
```
> Header больше не показывает под-табы продуктов (убраны секционные `headerNav`). Навигацию внутри `/docs/*` берёт на себя **сайдбар-дерево** `app/docs/layout.tsx` (с поиском по дереву; на мобильном — шторка). Данные каталога централизованы в `src/data/docs/catalog.ts`.

### Школа (`/school/*`)
```
UCS service | Документация | Школа | 🔍   ← «Главная»/«Курсы» под-табы убраны
```
> Школа — публичный открытый каталог-тренажёр: все уроки доступны, прогресс сохраняется локально (`localStorage` `ucs_school_progress`, без backend). В деталях курса и на уроках — отметки пройденного и панель прогресса. Разделы профиля, рейтинга, бейджей, сертификатов и уведомлений удалены. См. `docs/touchpoints.md`.

### Горячие клавиши (глобальные)
| Клавиша | Действие | Где срабатывает |
|---------|----------|-----------------|
| `Ctrl + 5` | Открыть поиск (`SearchDialog`) | везде |
| `1` | → `/docs` | только лендинг `/` |
| `2` | → `/school` | только лендинг `/` |
| `3` | → `/docs/cases` | только лендинг `/` |

> Реализация — `components/layout/Hotkeys.tsx`, смонтирован в `layout.tsx`. Не срабатывает при вводе в полях ввода (`input`/`textarea`/`contentEditable`). `Ctrl+K` и `/` убраны: первый браузер использует для поиска, `/` печатается в полях ввода — конфликты устранены; вместо них — `Ctrl + 5` (по требованию владельца; в обычной вкладке браузер резервирует `Ctrl+1..8` под переключение вкладок, поэтому в PWA/standalone-окне работает надёжнее). Цифровые шорткаты `1/2/3` ограничены лендингом, чтобы не конфликтовать с выбором ответов в квизах/тренажёрах школы.

## 2. Cross-links — недостающие связи

### Кейсы месяца ↔ тренажёр (публичный контур)
| Откуда | Ссылка | Куда |
|--------|--------|------|
| `/docs` (блок «Кейсы месяца») | `/docs/cases` | хаб кейсов |
| `/docs/cases` | `/school/courses/cases-2026-07` | курс-тренажёр |
| `/docs/cases/[id]` | `/school/courses/cases-2026-07/lessons/{trainerLessonId}` | урок по кейсу |

### Урок школы (без CTA на запись)
| Откуда | Ссылка | Куда |
|--------|--------|------|
| завершённый урок | «Следующий урок» | следующий урок курса |
| завершённый урок | «К курсу» | `/school/courses/[id]` |
| завершённый урок | «В школу» | `/school` |

### Входы в публичные разделы
| Элемент | Ссылка |
|---------|--------|
| Лендинг Hero → школа | `/school` |
| Лендинг Hero → документация | `/docs` |
| Лендинг Hero-хайлайты | `/docs`, `/school`, `/docs/cases` |
| Горячая клавиша `1/2/3` | `/docs`, `/school`, `/docs/cases` |
| Поиск (Ctrl + 5) | `/docs`, `/school`, `/docs/cases`, `/school/courses/{id}` |
| Сайдбар `/docs/*` → подразделы, кейсы | `/docs/rkeeper/{product}`, `/docs/cases` |
| Footer → школа / курсы / документация / кейсы | `/school`, `/school/courses`, `/docs`, `/docs/cases` |

## 3. Breadcrumbs — единый формат

### Текущая реализация (Breadcrumbs.tsx)
- Автоматически генерируется из URL-path
- Использует `routeLabels` из navigation.json
- Скрывает динамические сегменты (`[id]`, `[lid]`, `[token]` — `skipSegments`) и служебные сегменты-папки (`rkeeper`, `lessons` — `hiddenSegments`)
- «Главная» — первая крошка для всех страниц кроме `/` (с иконкой Home)
- UI: glass-капсула (`rounded-full`), chevron-разделители, текущий уровень `font-semibold` + `aria-current="page"`

> Все `routeLabels` соответствуют живым маршрутам: `docs`, `school`, `courses`. Duplicate inline-крошки внутри страниц `/docs/rkeeper/*` удалены — используется единый компонент из layout.

## 4. Navigation JSON — структура

### Текущая структура sections (публичный контур)
```json
[
  { id: "home", label: "Главная", href: "/" },
  { id: "docs", label: "Документация", href: "/docs", groups: [..., { label: "Кейсы месяца", items: ["/docs/cases"] }], headerNav: [..., "/docs/cases"] },
  { id: "school", label: "Школа", href: "/school", headerNav: ["/school", "/school/courses"] }
]
```
> Секции «Личный кабинет» (`dashboard`), «Admin» и «Услуги» убраны — ЛК, админка и услуги удалены. Поля `headerNav` в `navigation.json` оставлены для справки, но в UI **не используются**: Header рендерит только табы топ-уровня, навигация по `/docs/*` — через сайдбар doc-центра.

| Страница | Добавить | Формат |
|----------|----------|--------|
| `/terms`, `/privacy`, `/offer`, `/consent` | "← Вернуться на сайт" ссылка вверху | `<Link href="/">← На главную</Link>` |
