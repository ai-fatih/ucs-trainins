# Navigation Architecture — UCS Service Portal

> **Текущая фаза — информационно-обучающий портал без ЛК** (см. `docs/brief-public-phase.md`). Авторизация, ЛК, админка, услуги/специалисты/заявка, отзывы/новости/FAQ и персонализация школы удалены; все маршруты публичные. Открыты `/`, `/docs`, `/docs/[id]`, `/faq`, `/faq/[month]`, `/faq/[month]/[caseId]`, `/school/*` и правовые страницы. Удалённая реализация сохранена в ветке `main-arhive` и в текущем контуре не возвращается.

## Принцип навигации

Каждая страница должна отвечать на 4 вопроса:
1. **Где я?** — breadcrumbs + заголовок
2. **Откуда я пришёл?** — ссылка "назад"
3. **Куда идти дальше?** — CTA или links
4. **Что ещё доступно?** — контекстная навигация (хедер/сайдбар)

## 1. Header — контекстная навигация

### Лендинг (`/`)
```
┌─────────────────────────────── header (fixed поверх hero) ─────────────────────────────┐
│  UCS service | Инструкции | Школа | Популярное | 🌙 🔍                                   │
└─────────────────────────────────────────────────────────────────────────────────────────┘
```
> На лендинге header — **оверлей поверх hero** (прозрачный, светлые табы/иконки под тёмный фон) — hero занимает ровно 100svh. Табы ведут на `/docs`, `/school`, `/faq`; якорных секций больше нет — лендинг это полноэкранный Hero-хаб без скролла, справа панель «Популярное · месяц» → `/faq`.

### Инструкции (`/docs/*`)
```
UCS service | Инструкции | Школа | Популярное | 🌙 🔍   ← Header sticky glass на остальных страницах
│  ┌───────────── sidebar (doc-центр) ─────────────┐
│  │ Все инструкции                                 │
│  │ Инструкции ▸ (список из instructions.json)     │
│  └────────────────────────────────────────────────┘   [контент страницы]
```
> Header больше не показывает под-табы продуктов (убраны секционные `headerNav`). Навигацию внутри `/docs/*` берёт на себя **сайдбар-дерево** `app/docs/layout.tsx` (с поиском по дереву; на мобильном — шторка). На `/docs` — живой список инструкций-процессов (`data/instructions.json`), карточки «Популярные обращения» (`/faq`) и «Официальная документация» (`docs.rkeeper.ru`). Популярные обращения вынесены в отдельный раздел `/faq`.

### Школа (`/school/*`)
```
UCS service | Инструкции | Школа | Популярное | 🔍   ← «Главная»/«Курсы» под-табы убраны
```
> Школа — публичный открытый каталог-тренажёр: все уроки доступны, прогресс сохраняется локально (`localStorage` `ucs_school_progress`, без backend). В деталях курса и на уроках — отметки пройденного и панель прогресса. Разделы профиля, рейтинга, бейджей, сертификатов и уведомлений удалены. См. `docs/touchpoints.md`.

### Горячие клавиши (глобальные)
| Клавиша | Действие | Где срабатывает |
|---------|----------|-----------------|
| `Ctrl + 5` | Открыть поиск (`SearchDialog`) | везде |
| `1` | → `/docs` | только лендинг `/` |
| `2` | → `/school` | только лендинг `/` |
| `3` | → `/faq` | только лендинг `/` |

> Реализация — `components/layout/Hotkeys.tsx`, смонтирован в `layout.tsx`. Не срабатывает при вводе в полях ввода (`input`/`textarea`/`contentEditable`). `Ctrl+K` и `/` убраны: первый браузер использует для поиска, `/` печатается в полях ввода — конфликты устранены; вместо них — `Ctrl + 5` (по требованию владельца; в обычной вкладке браузер резервирует `Ctrl+1..8` под переключение вкладок, поэтому в PWA/standalone-окне работает надёжнее). Цифровые шорткаты `1/2/3` ограничены лендингом, чтобы не конфликтовать с выбором ответов в квизах/тренажёрах школы.

## 2. Cross-links — недостающие связи

### Ядро: обращение → инструкция → школа
| Откуда | Ссылка | Куда |
|--------|--------|------|
| `/docs` (блок «Популярные обращения») | `/faq` | годовой срез обращений |
| `/faq` | `/faq/[month]` | месяц (сетка по годам) |
| `/faq/[month]` | `/faq/[month]/[caseId]` | обращение |
| `/faq/[month]/[caseId]` | `/docs/[instructionId]` | полная инструкция («Читать инструкцию») |
| `/faq/[month]/[caseId]` | `/school/courses/{courseId}/lessons/{lessonId}` | урок-тренажёр («Потренироваться в школе») |
| `/docs/[id]` | `/faq/2026-07/[caseId]` | «из каких обращений» (`sourceCaseIds`) |
| `/docs/[id]` | `/school/courses/{courseId}/lessons/{lessonId}` | тренировка по инструкции |

### Урок школы (без CTA на запись)
| Откуда | Ссылка | Куда |
|--------|--------|------|
| завершённый урок | «Следующий урок» | следующий урок курса |
| завершённый урок | «К курсу» | `/school/courses/[id]` |
| завершённый урок | «В школу» | `/school` |

### Входы в публичные разделы
| Элемент | Ссылка |
|---------|--------|
| Лендинг Hero → школа | `/school` |
| Лендинг Hero → документация | `/docs` |
| Лендинг Hero-панель «Популярное» | `/faq` |
| Горячая клавиша `1/2/3` | `/docs`, `/school`, `/faq` |
| Поиск (Ctrl + 5) | `/docs`, `/docs/[id]`, `/school`, `/faq`, `/faq/[month]`, `/school/courses/{id}` |
| Сайдбар `/docs/*` → инструкции | `/docs/[id]` |
| Footer → школа / курсы / документация / обращения | `/school`, `/school/courses`, `/docs`, `/faq` |

## 3. Breadcrumbs — единый формат

### Текущая реализация (Breadcrumbs.tsx)
- Автоматически генерируется из URL-path
- Использует `routeLabels` из navigation.json
- Скрывает динамические сегменты (`[id]`, `[lid]`, `[token]` — `skipSegments`) и служебные сегменты-папки (`rkeeper`, `lessons` — `hiddenSegments`)
- «Главная» — первая крошка для всех страниц кроме `/` (с иконкой Home)
- UI: glass-капсула (`rounded-full`), chevron-разделители, текущий уровень `font-semibold` + `aria-current="page"`

> Все `routeLabels` соответствуют живым маршрутам: `docs`, `school`, `courses`. Duplicate inline-крошки внутри страниц `/docs/rkeeper/*` удалены — используется единый компонент из layout.

## 4. Navigation JSON — структура

### Текущая структура sections (публичный контур)
```json
[
  { id: "home", label: "Главная", href: "/" },
  { id: "faq", label: "Популярные обращения", href: "/faq", icon: "TrendingUp", headerNav: ["/faq", "/faq/2026-07"] },
  { id: "docs", label: "Инструкции", href: "/docs", groups: [], headerNav: ["/docs"] },
  { id: "school", label: "Школа", href: "/school", headerNav: ["/school", "/school/courses"] }
]
```
> Секции «Личный кабинет» (`dashboard`), «Admin» и «Услуги» убраны — ЛК, админка и услуги удалены. Поля `headerNav` в `navigation.json` оставлены для справки, но в UI **не используются**: Header рендерит только табы топ-уровня, навигация по `/docs/*` — через сайдбар doc-центра, обращения — отдельный раздел `/faq`.
