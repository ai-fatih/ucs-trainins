# Документация проекта — индекс

Единая база знаний по проекту **UCS Trainings** (UCS Service Portal).

> **Живая база команды** (контент-план, решения, встречи, материалы менеджеров/маркетинга) ведётся в **Notion** — ссылка добавляется по факту создания. Здесь — канон: правила, тех. документация, точки касания, сценарии, функционал.

## Быстрый старт

- `README.md` (корень) — онбординг: запуск, окружения, деплой, сценарии.
- `AGENTS.md` (корень) — правила для AI-агентов (гидрация, команды, конвенции).
- `design-vars/` — HTML-прототипы и варианты дизайна для согласования.

## Правила ведения

1. **Каноническая документация** живёт в `docs/` и версионируется с кодом (PR-review).
2. Новые правила для AI-агентов → `AGENTS.md` (корень).
3. **Изменение правил точек касания или функционала** → обновить `touchpoints.md` и `feature-inventory.md` в том же PR, что и код.
4. **Живые документы команды** (контент, встречи, решения) → Notion, в репозитории — только ссылки.
5. **Варианты дизайна на согласование** → `design-vars/` (например, `vars-hero-banner.html`), отдельный файл на тему.
