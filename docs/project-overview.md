# Проект UCS Trainings — Полный обзор

> **Актуализация 03.08.2026:** текущая фаза — **информационно-обучающий портал без ЛК** (см. `docs/brief-public-phase.md`). Авторизация, личный кабинет, админка и персонализация школы удалены. Реализация ЛК сохранена в ветке `main-arhive` и вернётся только после получения одобрения/API.

## 1. О проекте

**UCS Trainings** (также UCS Service Portal) — веб-платформа отдела консультации и обучения пользовательской части **rkeeper**. Разрабатывается для ООО ЦТО «ЮСИЭС сервис».

### 1.1. Миссия

Помогать пользователям rkeeper разобраться и научиться работать с программой. Мы не настраиваем и не чиним — мы консультируем и обучаем. Наш результат — пользователь, который умеет работать.

### 1.2. Видение

Открытый информационно-обучающий портал: школа с курсами и тренажёрами на реальных кейсах, документация по продуктам, кейсы месяца и публичный сбор обращений. Личный кабинет и аналитика — следующий этап после одобрения/API.

### 1.3. Цель

Развивать открытый контент отдела (база знаний, обучение, кейсы) без зависимости от внешних API: любой пользователь может изучать инструкции и тренироваться на кейсах без входа.

---

## 2. Задачи

### 2.1. Для пользователей (публично, без входа)
- **Документация** по продуктам rkeeper (пошаговые инструкции, сценарии)
- **Кейсы месяца** — разборы реальных обращений по единому шаблону
- **Школа** — открытый каталог курсов и уроков (квизы, спринты, сопоставления, цепочки, деревья решений); все уроки доступны без регистрации

### 2.2. Для отдела
- Ежемесячное оформление топ-кейсов в едином шаблоне
- Обновление учебного контента в репозитории

### 2.3. Инфраструктурные
- Обработка ПДн в соответствии с 152-ФЗ, 149-ФЗ, 242-ФЗ
- Rate limiting, helmet, CORS (health-only backend)

## 3. Ценности проекта

| Ценность | Проявление |
|----------|-----------|
| **Помощь, а не техподдержка** | Мы консультируем и обучаем, а не настраиваем — это чётко проведено через весь контент-гайд |
| **Пользователь в центре** | Результат = пользователь, который разобрался. Не «система настроена», а «клиент научился» |
| **Открытость** | Обучение и документация доступны без регистрации |
| **База знаний как актив** | Реальные кейсы обращений оформляются в единый шаблон и обучающий контент |
| **Безопасность и комплаенс** | Full compliance с 152-ФЗ, 149-ФЗ, 242-ФЗ; cookie-banner, оферта, политика |
| **Enterprise-качество** | TypeScript full-stack, NestJS + Prisma, модульная архитектура |

## 4. Ключевые преимущества (USP)

1. **Специализированность** — контент, заточенный под обучение и консультации по rkeeper
2. **Открытый доступ** — инструкции, кейсы и тренажёры без регистрации
3. **Тренажёры на реальных кейсах** — деревья решений на основе фактических обращений
4. **Feedback без входа** — одноразовые ссылки для оценки после консультации
5. **Документация** — встроенный каталог инструкций и сценариев по всем продуктам rkeeper
6. **Full compliance 152-ФЗ** — cookie-banner, политика, оферта, согласие
7. **Модульная архитектура** — backend на NestJS + Prisma, готов к будущей ITSM-интеграции

## 5. Архитектура

```
Browser
  ├── Next.js frontend (Vercel)
  │     ├── App Router страницы (лендинг, документация, кейсы, школа, юридические)
  │     ├── PWA / service worker (offline-кеш /school/** и /docs/**)
  │     └── Данные (JSON каталоги в src/data)
  └── REST → NestJS backend (health-only: GET /health)
```

### 5.1. Frontend (apps/frontend)

Next.js (App Router) + React + TypeScript + Tailwind CSS.

**Ключевые библиотеки:**
- **Zustand 5** — client-side состояние (UI)
- **@serwist/next** — PWA (service worker, precaching, offline-кеш контента)
- **lucide-react** — иконки

**Страницы:**
- Публичные: лендинг (`/`), документация (`/docs/*`), кейсы (`/docs/cases`), школа (`/school/*`)
- Юридические: privacy, terms, offer, consent

### 5.2. Backend (apps/backend)

NestJS — свёрнут до health-эндпоинта `GET /health` (AppModule + HealthController). Модули заявок/feedback/consent/prisma удалены.

**Безопасность:**
- Helmet (security headers)
- Throttler (rate limiting)
- CORS (строгий origin из `FRONTEND_URL`)
- Pino logger (redact cookies + authorization)

### 5.3. Модели данных (Prisma)

`schema.prisma` + `seed.ts` остаются в репозитории без миграций. Модели `AdminUser`, `AdminAuditLog` не используются.

## 6. Статус реализации

### Реализовано (backend)
- ✅ Health-only: `GET /health`
- ✅ Rate limiting, helmet, CORS, Pino логирование

### Реализовано (frontend)
- ✅ Лендинг: полноэкранный Hero-хаб (0 скролла) с CTA на `/docs`/`/school` (контакты — только в Footer)
- ✅ Каталог документации → doc-центр: сайдбар-дерево + поиск по дереву + мобильная шторка (`app/docs/layout.tsx`, данные в `data/docs/catalog.ts`)
- ✅ Кейсы месяца (шаблон «ситуация → … → профилактика») + связь с тренажёром
- ✅ Школа — тренажёр: hero «Школа — это тренажёр», skills в курсах, бейдж «Тренажёр», блок «Скоро», открытый каталог уроков; прогресс хранится локально (`ucs_school_progress`): панель прогресса курса, отметки пройденных уроков, «Продолжить урок», баннер «урок уже пройден»
- ✅ Документация `/docs/*`: prev/next между инструкциями (`InstructionPager`), содержание страницы TOC (якоря шагов), «Печать / PDF» (`@media print` без сайдбара/шапки/футера); поиск по кейсам в URL (`?q=…`)
- ✅ Навигация: единый поиск `SearchDialog` (`Ctrl + 5`, группировка результатов), горячие клавиши `1/2/3` на лендинге, glass-хлебные крошки; Header — табы топ-уровня
- ✅ Тёмная/светлая тема: тумблер `ThemeToggle` в Header, `ucs_theme`, сквозная (без FOUC), по умолчанию — системная схема
- ✅ Система подсказок: hover-тултипы (`Tooltip`) + карточки «Что здесь / что сделано» (`PageHelp` + `data/help.ts`) у заголовков главных страниц
- ✅ Кастомная 404 + scroll-to-top при переходах
- ✅ PWA support (@serwist/next) + offline-кеш контента `/school/**`, `/docs/**`

### Удалено в текущем контуре (реализация в `main-arhive`)
- ❌ Авторизация, ЛК (запись, чат, отзывы, профиль, уведомления)
- ❌ Админка (вход, дашборд, заявки, расписание, CRUD)
- ❌ Услуги, специалисты, публичная заявка, feedback
- ❌ Голосовой ассистент, прелоадер, инлайн-поиск на `/docs` *(сайдбар-шторка в `/docs/*` добавлена как часть doc-центра)*
- ❌ Геймификация школы (XP, уровни, бейджи, рейтинг, сертификаты, мини-игры) и сохранение прогресса

### Планируется (roadmap, после одобрения/API)
- ⏳ ЛК: авторизация, запись, чат, отзывы
- ⏳ Услуги/специалисты, публичная заявка
- ⏳ Админка: заявки, дашборды
