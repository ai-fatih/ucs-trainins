# Проект UCS Trainings — Полный обзор

## 1. О проекте

**UCS Trainings** (также UCS Service Portal) — веб-платформа отдела консультации и обучения пользовательской части **rkeeper**. Разрабатывается для ООО ЦТО «ЮСИЭС сервис».

### 1.1. Миссия

Помогать пользователям rkeeper разобраться и научиться работать с программой. Мы не настраиваем и не чиним — мы консультируем и обучаем. Наш результат — пользователь, который умеет работать.

### 1.2. Видение

Стать единой цифровой экосистемой для клиентов rkeeper, объединяющей обучение (школа с геймификацией), консультации (запись, чат, отзывы), документацию (инструкции по продуктам) и аналитику (дашборды).

### 1.3. Цель

Разработать веб-приложение для оптимизации процессов отдела консультации и обучения: автоматизация записи, коммуникации, оценки и аналитики.

---

## 2. Задачи

### 2.1. Для клиентов
- **Авторизация:** юрлица — через ITSM по номеру договора; физлица — регистрация по email/телефону
- **Запись на услуги** в 3–5 кликов (выбор услуги → специалиста → даты/времени → подтверждение)
- **Управление записями:** просмотр, отмена, перенос, история
- **Чат** со специалистами отдела в реальном времени
- **Оценка и отзывы** после консультации (звёзды + комментарий)
- **Уведомления:** email (MVP), Telegram/SMS (post-MVP)
- **Школа:** курсы, уроки, XP, уровни, бейджи, рейтинг, сертификаты

### 2.2. Для специалистов и администраторов
- **Управление заявками:** список, карточка, статусы (`new → in_progress → done / rejected`), комментарии
- **CRUD услуг и специалистов**
- **Управление расписанием**
- **Дашборд:** KPI, загрузка специалистов, NPS, статистика
- **Генерация feedback-ссылок** для сбора оценок
- **Аудит-лог** всех действий

### 2.3. Инфраструктурные
- Интеграция с ITSM для авторизации юрлиц и синхронизации данных
- Обработка ПДн в соответствии с 152-ФЗ, 149-ФЗ, 242-ФЗ
- Локализация данных на территории РФ
- Rate limiting, CSP, HTTPS, bcrypt, httpOnly cookies

## 3. Ценности проекта

| Ценность | Проявление |
|----------|-----------|
| **Помощь, а не техподдержка** | Мы консультируем и обучаем, а не настраиваем — это чётко проведено через весь контент-гайд |
| **Пользователь в центре** | Результат = пользователь, который разобрался. Не «система настроена», а «клиент научился» |

| **Геймификация обучения** | XP, уровни, бейджи, рейтинг — мотивация через игру |
| **Безопасность и комплаенс** | Full compliance с 152-ФЗ, 149-ФЗ, 242-ФЗ; bcrypt, httpOnly cookies, CSP, HTTPS |
| **Enterprise-качество** | TypeScript full-stack, NestJS + Prisma, модульная архитектура, готовность к ITSM-интеграции |

## 4. Ключевые преимущества (USP)

1. **Специализированность** — не абстрактная платформа, а система, заточенная под обучение и консультации по rkeeper
2. **Две категории пользователей** — юрлица (через ITSM) и физлица (регистрация), с разными флоу
3. **Геймификация** — школа обучения с XP, уровнями, бейджами, рейтингом и сертификатами (уникально для рынка консультаций)
4. **Feedback без входа** — одноразовые ссылки для оценки после консультации (не нужно регистрироваться)
5. **Чат в реальном времени** — прямая коммуникация со специалистами
6. **Документация** — встроенный каталог инструкций и сценариев по всем продуктам rkeeper
7. **Full compliance 152-ФЗ** — все формы с согласием, cookie-banner, политика, оферта, право на забвение
8. **Модульная архитектура** — backend на NestJS + Prisma, готов к ITSM-интеграции, масштабируем

## 5. Архитектура

```
Browser
  ├── Next.js 14 frontend (Vercel)
  │     ├── App Router страницы (лендинг, услуги, запись, школа,
  │     │   документация, админка, профиль, чат)
  │     ├── API-клиент (api-client.ts) → NestJS backend
  │     └── Мок-данные (~15 статических JSON, ~75% UI)
  └── REST + httpOnly cookie → NestJS 11 backend
                                └── Prisma 6 ORM → PostgreSQL
                                    ├── AdminUser, Request, RequestComment,
                                    │   RequestHistory, ConsentLog, AdminAuditLog
                                    └── Индексы, миграции, bcrypt seed
```

### 5.1. Frontend (apps/frontend)

Next.js 14 (App Router) + React 18 + TypeScript + Tailwind CSS.

**Ключевые библиотеки:**
- **Zustand 5** — управление client-side состоянием (auth, booking, notifications, UI)
- **@tanstack/react-query 5** — серверное состояние, кэширование
- **Zod 3** — валидация форм
- **@serwist/next** — PWA (service worker, precaching)
- **Phaser.js 3** — мини-игры в Школе
- **lucide-react** — иконки

**Страницы:**
- Публичные: лендинг (`/`), документация (`/docs/*`), услуги (`/services`), заявка (`/request`), feedback (`/feedback/[token]`)
- Пользовательские: дашборд (`/dashboard`), запись (`/booking`), мои записи (`/bookings`), чат (`/chat`), профиль (`/profile`), школа (`/school/*`), отзыв (`/review`)
- Админские: вход (`/admin/login`), дашборд (`/admin/dashboard`), заявки (`/admin/requests`), карточка (`/admin/requests/[id]`)
- Юридические: privacy, terms, offer, consent

### 5.2. Backend (apps/backend)

NestJS 11 + Prisma 6 + PostgreSQL.

**Модули:**
- `AuthModule` — JWT-авторизация (httpOnly cookie), bcrypt (cost 12), CookieAuthGuard
- `RequestsModule` — CRUD заявок, комментарии, история статусов
- `FeedbackModule` — генерация одноразовых feedback-ссылок, сбор оценок
- `ConsentModule` — логирование согласий на обработку ПДн
- `AuditModule` — аудит-лог действий администраторов

**Безопасность:**
- Helmet (security headers)
- Throttler (rate limiting: 10 req/s, 100 req/min)
- CORS (строгий origin из `FRONTEND_URL`)
- ValidationPipe (whitelist, forbidNonWhitelisted, transform)
- Pino logger (redact cookies + authorization)
- CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy

### 5.3. Модели данных (Prisma)

- `AdminUser` — администратор (email + bcrypt-hash)
- `Request` — заявка на консультацию (номер, статус, тип услуги, feedback-token)
- `RequestComment` — внутренние комментарии администраторов
- `RequestHistory` — история переходов статусов
- `ConsentLog` — логи согласий на обработку ПДн
- `AdminAuditLog` — аудит действий администраторов

- ✅ Rate limiting, helmet, CORS, Pino логирование
