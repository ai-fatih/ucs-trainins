# Состояние конвейера разбора обращений

Собери сводку по данным в репозитории и верни структурированный отчёт:

## 1. Кейсы по месяцам
Из `src/data/cases/yearly.json`: общее число кейсов по каждому месяцу 2026 года, помеченные planned (будущие месяцы).

## 2. Инструкции
Из `src/data/instructions.json`:
- сколько всего инструкций, сколько `stub: false` (готовых);
- список готовых по месяцам (по id: префикс `ins-*` или связанные sourceCaseIds);
- список заглушек, ожидающих конвейера.

## 3. Уроки-тренажёры
Из `src/data/school/courses.json`:
- сколько уроков с `stub: false`;
- какие типы activity используются (quiz/case/sprint/match/chain);
- сколько уроков осталось заглушками.

## 4. Черновики и маркетинг
- `content-drafts/` — какие кейсы в работе;
- `Marketing/articles/` и `Marketing/social/` — сколько материалов готово.

## 5. Движок тренажёров
- Готов ли LessonView (не заглушка ли) — проверь `src/components/school/LessonView.tsx`.

## Формат
Сводная таблица по месяцам (месяц / кейсы / инструкции готовы / уроки готовы) + списки незакрытых пунктов. Отметь следующий шаг, который нужно сделать.
