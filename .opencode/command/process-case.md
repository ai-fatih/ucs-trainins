# Конвейер обработки кейса

Запусти полный конвейер для кейса `$ARGUMENTS` из `src/data/cases/yearly.json`.

## Данные кейса
Найди кейс по id в `src/data/cases/yearly.json`. Возьми: title, question, product, category, tags, месяц. Также проверь, есть ли уже связанные записи: инструкция `ins-*` в `src/data/instructions.json` и урок `case-*-aug-train` в `src/data/school/courses.json`.

## Этапы (используй Task tool, subagents из .opencode/agent/)

### 1. Сценарий — support-manager
Передай агенту данные кейса. Получи живой сценарий: кто обратился, что случилось, суть, что важно для обучения.

### 2. Факты — rkeeper-expert
Передай кейс и сценарий. Агент через webfetch/docs.rkeeper.ru даёт проверенные факты со ссылками. Если документация недоступна — отметь это и продолжай, пометив факты как «на проверку».

### 3. ТЗ — methodologist
Передай кейс, сценарий и факты эксперта. Получи ТЗ: структуру steps, commonErrors, теги; рекомендацию по типу тренажёра.

### 4. Инструкция — writer
Передай кейс, сценарий, факты, ТЗ. Получи готовый JSON инструкции.

### 5. Ревью — reviewer
Передай кейс, ТЗ, факты и черновик инструкции. Вердикт:
- «ДОРАБОТАТЬ» → передай замечания writer'у (Task tool с новым контекстом), повторяй до «ПРИНЯТЬ» (максимум 3 итерации).
- «ПРИНЯТЬ» → переходи дальше.

### 6. Утверждение — support-lead
Передай кейс, сценарий, финальную инструкцию и вердикт ревьюера. Получи «УТВЕРЖДЕНО» или замечания (при замечаниях — вернись к шагу 5).

## Артефакты (запиши файлы)

- Черновик инструкции: `content-drafts/<месяц>/<caseId>/instruction.md` — JSON-блок инструкции + краткое пояснение.
- Черновик тренажёра: `content-drafts/<месяц>/<caseId>/trainer.md` — JSON-блок activity (заполняется позже, на этапе тренажёров, если движок ещё не готов).
- Маркетинг: `Marketing/articles/<месяц>/<caseId>.md` (если агент готов).
- SMM: `Marketing/social/<месяц>/<caseId>.md` (если агент готов).

**Внимание**: если движок тренажёров ещё не реализован — пропусти шаг тренажёра, отметь в trainer.md «движок не готов», и не запускай teacher.

## Итоговый отчёт
Верни сводку: кейс, вердикт ревью, путь к артефактам, замечания, что осталось сделать.
