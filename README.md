# UCS Trainings

**Информационно-обучающий портал по rkeeper.** Открытый (без личного кабинета) веб-проект отдела консультации и обучения пользовательской части rkeeper: документация, кейсы месяца и школа-тренажёр.

Проект состоит из независимого Next.js frontend и NestJS backend. Frontend отвечает за интерфейс (контент — статические JSON-каталоги в `src/data`), backend свёрнут до health-эндпоинта `GET /health`.

**Компания:** ООО ЦТО «ЮСИЭС сервис» (ОГРН 1037723040871, ИНН 7723347991)

> **Текущая фаза:** публичный портал без ЛК (см. `docs/brief-public-phase.md`). Авторизация, админка, услуги/заявка, отзывы и персонализация школы удалены; реализация ЛК сохранена в ветке `main-arhive`.

## Миссия

> Помогать пользователям rkeeper **разобраться и научиться** работать с программой. Мы не настраиваем и не чиним — мы консультируем и обучаем. Наш результат — **пользователь, который умеет работать**, а не «система, которая настроена».

## Видение

Открытый информационно-обучающий портал: **обучение** (школа с курсами и тренажёрами на реальных кейсах), **документация** (инструкции по продуктам) и **кейсы месяца**. Личный кабинет и аналитика — следующий этап после одобрения/API.

## Цели и задачи

- **Обучение** — школа с курсами, квизами, спринтами и тренажёрами на реальных кейсах
- **Документация** — каталог сценариев по всем продуктам rkeeper
- **Кейсы месяца** — разборы реальных обращений по единому шаблону
- **Offline-доступ** — PWA кеширует `/docs/**` и `/school/**` (NetworkFirst)
- **Security & Compliance** — полное соответствие 152-ФЗ, 149-ФЗ, 242-ФЗ

## Ценности

| Ценность | Описание |
|----------|----------|
| **Помощь, а не техподдержка** | Консультируем и обучаем, а не настраиваем |

```text

├── frontend/   # Next.js, React, TypeScript, Tailwind CSS

    │   ├── app.module.ts  # Config, Logger, Throttler
    │   └── health.controller.ts
    └── prisma/
        ├── schema.prisma  # Модели (без миграций)

├── architecture.md
├── requirements.md
├── project-audit.md
├── backend-handoff.md
├── content-guide.md

```

## Требования и установка

- Node.js 20+
- npm

```bash
npm install
```

## Backend env

Создайте `apps/backend/.env` по образцу `apps/backend/.env.example`:

```env
FRONTEND_URL=http://localhost:3000
PORT=4000
```

## Локальный запуск

Frontend:

```bash
npm run dev:frontend
```

Backend:

```bash
npm run dev:backend
```

Проверка backend:

```bash
curl http://localhost:4000/health
```

Ожидаемый ответ: `{"status":"ok"}`.

## Проверки

```bash
npm run typecheck
npm run build:frontend
npm run build:backend
```

## Деплой

Frontend деплоится на Vercel. Root Directory должен быть `apps/frontend`. Backend (health-only) деплоится отдельно на Node.js-платформу; в production задаются backend env и точный frontend origin в `FRONTEND_URL`.
